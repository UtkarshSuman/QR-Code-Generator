QR Code Generator (Node.js)

A simple Node.js application that lets you enter any URL and automatically generates a QR code PNG and a text file containing the URL.
It can also auto-open the QR image after creation (optional).

🚀 Features

✔ Prompt user for any URL

✔ Generate a QR code image (qr_img.png)

✔ Save the URL in URL.txt

✔ Automatically open the QR code after generating.

✔ Clean and simple code using ES Modules + async/await
